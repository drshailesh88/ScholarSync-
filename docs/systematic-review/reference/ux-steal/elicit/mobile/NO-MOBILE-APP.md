# Elicit on Mobile — The Missing Surface (our wedge)

**Finding: Elicit has no catalogued native mobile experience.**

A Mobbin search on the **iOS** platform for "Elicit research assistant find papers"
returned **zero Elicit screens** — only ChatGPT, Google Gemini, Perplexity, and Grok
appeared. Mobbin catalogues Elicit exclusively as a **web** app. Elicit ships no native
iOS/Android app, and its product (a dense, multi-column evidence matrix with a right-hand
column-management rail) is fundamentally a desktop-grid experience.

What this means for ScholarSync:

- There is **no Elicit mobile pattern to copy** — there is a vacuum to design into.
- Elicit's core artifact, the **papers × attribute-columns matrix**, does not survive a
  390px viewport. Horizontal scrolling of a 4-8 column data grid on a phone is the exact
  failure mode our mobile-co-equal mandate exists to beat.
- Every desktop surface captured in the sibling folders must be **re-conceived** for mobile
  (card stacks, swipeable column chips, progressive disclosure, bottom-sheet column editors).
  See the "How Elicit's dense desktop matrix must be reimagined for mobile" section of
  `../elicit-ux-analysis.md`.

This folder is intentionally empty of screenshots: the absence *is* the data point.
